# SHA256 of the benchmark dataset archives.
#
# Recorded on first download, then verified on every run after. What they are NOT is a
# cross-check against an upstream published digest: corpus-texmex.irisa.fr and
# ann-benchmarks.com do not publish one, so there is nothing to compare against.
#
# What gives them weight is the loader. Every archive here was extracted and loaded with
# `anka load`, which asserts the exact expected shape — SIFT1M as 1 000 000 x 128 with a
# 10 000 x 100 ground truth, GloVe as 1 183 514 x 100 — and the reference kernel then reproduced
# each dataset's published neighbour list exactly (docs/RESULTS.md, section 2). An archive that
# was the wrong file, truncated, or corrupted could not have passed that.
#
# So these pin "the bytes that produced the published measurements", which is what
# reproducibility needs, rather than "the bytes the authors intended", which cannot be checked.
